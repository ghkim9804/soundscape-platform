# 이미지 파일 명명 규칙

## 형식
```
{장소코드}_{카테고리}_{비율}.{확장자}
```

## 예시
| 파일명 | 장소 | 카테고리 | 비율 |
|--------|------|----------|------|
| L1_vegetation_20.jpg | 장소 1 | 식생 | 20% |
| L1_vegetation_40.jpg | 장소 1 | 식생 | 40% |
| L2_vehicle_60.png   | 장소 2 | 차량 | 60% |
| L3_human_80.jpg     | 장소 3 | 인간 | 80% |

## 규칙
- **장소코드**: `L1` ~ `L6` (총 6개 장소)
- **카테고리**: `vegetation` (식생), `vehicle` (차량), `human` (인간)
- **비율**: `20`, `40`, `60`, `80`
- **확장자**: `.jpg`, `.jpeg`, `.png`, `.webp` 지원

## 전체 파일 목록 (72개)
6장소 × 3카테고리 × 4비율 = 72개 이미지
```
L1_vegetation_20.jpg  L1_vegetation_40.jpg  L1_vegetation_60.jpg  L1_vegetation_80.jpg
L1_vehicle_20.jpg     L1_vehicle_40.jpg     L1_vehicle_60.jpg     L1_vehicle_80.jpg
L1_human_20.jpg       L1_human_40.jpg       L1_human_60.jpg       L1_human_80.jpg
L2_vegetation_20.jpg  ... (동일 패턴)
...
L6_human_80.jpg
```

> **주의**: 대응하는 음원 파일이 없는 이미지는 자극 목록에서 제외됩니다.
